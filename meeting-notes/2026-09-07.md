### What "user facing" features do we need in the public server list
This is a current brainstorming of features that should be visible and presented to users on the Matrix Homeserver trusted list:

- Server Side Embeds (Link preview)
- Room directory
    - Public
    - Acessibly for users
- Calls
- Bridges
    - Which bridges
- Managed Moderation Services (allow users to access moderation tools for their own rooms/spaces)
- Managed Bots
    - which bots (webhooks, games, etc.)
- Files / attachments limits or restrictions
- Messages and content retention time (messages or attachment deleted after XX days/weeks/months/years)
- Country where the Homeserver is hosted
- What matrix username will you get on this server (@my-new-username:domain.tld)
- Authentication flows (External authentication providers / legacy local password / etc)
- Server Age
