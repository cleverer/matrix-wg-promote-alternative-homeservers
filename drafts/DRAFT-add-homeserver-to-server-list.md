# Adding homeservers to the list

## Required information 

### Technical details

- what is the homeserver software
- is it on a recent version
- is IPv4 available
- is IPv6 available
- what is the uptime percentage
- are there any backups of the homeserver data
- is it on a second-level domain
- is the top level domain trustworthy (is it not free, like e.g. freenom offers)

### Registration

- is OIDC available
- is legacy authentication available
- what personal information is required to register

### Federation

- does the homeserver federates

### Administration contact

- does the homeserver have a homepage with relevant information
- is there an official support chatroom for homeserver users
- is the @owner:thatparticular.host regularly pinging in some TWIM-like chatroom
- does the homeserver implement the [well-known support endpoing](https://spec.matrix.org/unstable/client-server-api/#getwell-knownmatrixsupport)

### Legal

- what is the country/legislation of the ISP
- what is the country/legislation of the owner

### Statistics

- does the homeserver have a public room directory
- number of registered users on the homeserver (define an allowed maximum to prevent centralization)

### Sensitivities

- is the homeserver not matrix.org
- is the homeserver not operated by Element Matrix Services
- is the homeserver not banned by Community Moderation Effort ban list
