# Removing a homeserver from the list
This document contains process and conditions under which a homeserver can be removed from the "trusted" list.

## Conditions of removal
Homeserver removed from the trusted list if:

* Homeserver administration / moderation contact opt out of the list
* Homeserver closes the open registration process
* Homeserver yearly uptime percentage below `TBD`% or Homeserver unreachable or down for more than `TBD` hours
* Homeserver administration / moderation contact unreachable for more than `TBD` hours/days
* Homeserver user base exceed `TBD` users
* Homeserver software version not updated for more than `TBD` weeks
* Homeserver involved in spam campaign

## Conditions for temporary flagged as "not ready for new registration"
Homeserver still present in the list but not currently suggested to new users:

* Homeserver administration / moderation contact request it (high load, planned maintenance, etc)
